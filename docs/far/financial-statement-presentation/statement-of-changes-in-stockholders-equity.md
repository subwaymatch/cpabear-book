# Statement of Changes in Stockholders' Equity

The **statement of changes in stockholders' equity** (also called the **statement of shareholders' equity**) reconciles the beginning and ending balance of each component of equity for the period. The balance sheet shows equity at a point in time, and the income statement shows one period's earnings; this statement shows how equity got from one balance sheet to the next. It is the linking statement: net income and other comprehensive income flow in from the period statements, owner transactions such as stock issuances and dividends are added, and the ending balances flow out to the equity section of the balance sheet. FAR asks you to prepare it from a trial balance, correct it, and agree it to supporting documents. This chapter covers what the statement must show, the items that change each column, a complete example, and the errors to look for.

---

## What the Statement Must Show

Under U.S. generally accepted accounting principles (GAAP), when both a balance sheet and an income statement are presented, the entity must disclose the changes in **each separate component** of stockholders' equity, and in the number of shares outstanding (ASC 505-10-50-2). Most entities meet this requirement with a separate statement, although the disclosure may appear in the notes. A statement of retained earnings alone is **not** enough, because it ignores contributed capital, accumulated other comprehensive income (AOCI), and treasury stock.

The statement is usually presented in a **columnar format**: each equity component is a column, and each type of transaction is a row. The columns are the components covered in the stockholders' equity chapter: preferred stock, common stock, additional paid-in capital (APIC), retained earnings, AOCI, treasury stock, and, in consolidated statements, noncontrolling interest (NCI).

## What Changes Each Column

Most transactions affect one or two columns, and knowing which ones is most of the work:

| Transaction | Columns affected | Effect on total equity |
| --- | --- | --- |
| Net income (or net loss) | Retained earnings | Increase (decrease) |
| Other comprehensive income (or loss) | AOCI | Increase (decrease) |
| Issuance of common or preferred stock | Stock at par; APIC for the excess | Increase |
| Exercise of stock options | Common stock and APIC | Increase |
| Purchase of treasury stock | Treasury stock (a deduction) | Decrease |
| Reissuance of treasury stock | Treasury stock; APIC (or retained earnings for a shortfall) | Increase |
| Cash or property dividends declared | Retained earnings | Decrease |
| Stock dividend declared | Retained earnings down; common stock and APIC up (APIC only for a small stock dividend) | None |
| Stock split | No dollar change; only par value per share and the number of shares | None |
| Prior period adjustment (error correction) | Beginning retained earnings, restated | Increase or decrease |

Two timing points cause many errors. Retained earnings is reduced when a dividend is **declared**, not when it is paid; payment only affects cash and dividends payable. And a prior period adjustment changes the **beginning** balance of retained earnings, net of tax, rather than flowing through current-period net income. The journal entries for all of these transactions are in the stockholders' equity chapter.

## A Complete Statement

Grizzly Inc. reports the following for the year:

**Statement of Changes in Stockholders' Equity, Year Ended December 31**

| | Preferred Stock | Common Stock | APIC | Retained Earnings | AOCI | Treasury Stock | Total |
|---|---:|---:|---:|---:|---:|---:|---:|
| **Jan. 1 balance** | \$100,000 | \$25,000 | \$275,000 | \$410,000 | \$8,000 | (\$15,000) | **\$803,000** |
| Net income | | | | 195,000 | | | 195,000 |
| OCI: AFS gain | | | | | 11,000 | | 11,000 |
| OCI: Translation loss | | | | | (5,000) | | (5,000) |
| Issuance of common stock | | 5,000 | 70,000 | | | | 75,000 |
| Common dividends declared | | | | (40,000) | | | (40,000) |
| Preferred dividends declared | | | | (8,000) | | | (8,000) |
| Treasury stock purchased | | | | | | (25,000) | (25,000) |
| **Dec. 31 balance** | **\$100,000** | **\$30,000** | **\$345,000** | **\$557,000** | **\$14,000** | **(\$40,000)** | **\$1,006,000** |

Each column foots to the ending balance on the balance sheet, and the Total column must equal both the sum of the ending balances across the bottom row and the beginning total plus every row. Checking both directions is the fastest way to catch a posting error.

### The Retained Earnings Column

The retained earnings column works as its own mini-statement:

$$
\text{Ending RE} = \text{Beginning RE} + \text{Net income} - \text{Dividends declared} \pm \text{Prior period adjustments}
$$

When an error from a prior year is corrected, the beginning balance is shown as previously reported, then adjusted, then restated. Sloth Security discovers that it omitted \$30,000 of depreciation in the prior year; at a 25% tax rate the correction is \$22,500 net of tax. It also declares a stock dividend recorded at \$100,000:

| Retained Earnings Reconciliation | Amount |
|---|---:|
| Beginning retained earnings (as previously reported) | \$500,000 |
| Prior period adjustment for error correction (net of tax) | (22,500) |
| **Beginning retained earnings (as restated)** | **\$477,500** |
| Add: Net income | 200,000 |
| Less: Cash dividends declared | (50,000) |
| Less: Stock dividends declared | (100,000) |
| **Ending retained earnings** | **\$527,500** |

### The AOCI Column

The AOCI column summarizes the period's OCI by type and shows any reclassifications into net income:

| AOCI Rollforward | Amount |
|---|---:|
| Beginning AOCI | \$15,000 |
| Unrealized gain on AFS debt securities (net of tax) | 8,000 |
| Foreign currency translation loss (net of tax) | (4,000) |
| Pension adjustment (net of tax) | (3,000) |
| Reclassification to net income (net of tax) | (2,000) |
| **Ending AOCI** | **\$14,000** |

### Noncontrolling Interest

In consolidated financial statements, NCI is presented within equity, separately from the parent's equity, in its own column. It increases for the noncontrolling shareholders' share of the subsidiary's net income and OCI, and decreases for dividends paid to them. A subsidiary's NCI that begins the year at \$45,000, is allocated \$12,000 of net income and \$2,000 of OCI, and receives \$5,000 of dividends ends the year at \$54,000.

## Connections to the Other Statements

The statement ties to every other statement, which is what makes it useful for finding errors:

- Net income in the retained earnings column must equal net income on the income statement (or the amount attributable to the parent, in consolidated statements).
- OCI in the AOCI column must equal total OCI in the statement of comprehensive income.
- Ending balances must equal the equity section of the balance sheet.
- Cash transactions with owners, such as stock issued for cash, dividends paid, and treasury stock purchases, appear as financing activities in the statement of cash flows. Dividends declared but not yet paid appear here but not in the cash flow statement.

:::warning[Common exam traps]

Large stock dividends are recorded at par value, not market value. A stock split changes no dollar amounts. OCI goes to the AOCI column, never to retained earnings, and the AOCI column cannot be left out of the statement.

:::

## Practice Problem

Cub Entertainment provides the following information for the year ended December 31:

- Beginning common stock (\$1 par): \$40,000
- Beginning APIC: \$360,000
- Beginning retained earnings: \$280,000
- Beginning AOCI: \$10,000
- Beginning treasury stock: (\$20,000)
- Net income: \$150,000
- OCI, unrealized gain on AFS (net of tax): \$7,000
- OCI, translation loss (net of tax): (\$3,000)
- Cash dividends declared: \$45,000
- Issued 5,000 shares at \$22 per share
- Purchased 1,000 shares of treasury stock at \$19 per share

**Required:** Prepare the statement of changes in stockholders' equity and calculate ending total equity.

<details>
<summary>Solution</summary>

| | Common Stock | APIC | Retained Earnings | AOCI | Treasury Stock | Total |
|---|---:|---:|---:|---:|---:|---:|
| **Beginning** | \$40,000 | \$360,000 | \$280,000 | \$10,000 | (\$20,000) | **\$670,000** |
| Net income | | | 150,000 | | | 150,000 |
| OCI: AFS gain | | | | 7,000 | | 7,000 |
| OCI: Translation loss | | | | (3,000) | | (3,000) |
| Stock issuance | 5,000 | 105,000 | | | | 110,000 |
| Cash dividends | | | (45,000) | | | (45,000) |
| Treasury stock | | | | | (19,000) | (19,000) |
| **Ending** | **\$45,000** | **\$465,000** | **\$385,000** | **\$14,000** | **(\$39,000)** | **\$870,000** |

The 5,000 new shares bring in \$110,000 (5,000 × \$22): \$5,000 to common stock at \$1 par and \$105,000 to APIC. The treasury stock purchase costs \$19,000 (1,000 × \$19).

</details>
